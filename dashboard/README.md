# Dashboard Power BI | Prueba técnica de Banca Digital

El análisis incluye un visualizador en Power BI Desktop como entregable original de la prueba de segmentación de comercios.

**Archivo:** [`Prueba_Analista_Datos_Banca_Digital.pbix`](Prueba_Analista_Datos_Banca_Digital.pbix).

Para abrirlo, instalar Power BI Desktop. Si aparecen errores de rutas, actualizar las fuentes a las tablas bajo `data/processed/` en la máquina de consulta. No se ha verificado despliegue en Power BI Service.

Consultar la documentación metodológica en [`06_Deployment`](../06_Deployment/README.md).
